# שעון מילים בעברית - פרויקט ESP32 e-Ink

הפרויקט הזה מכיל את כל מה שצריך כדי להריץ את השעון שראית בהדמיה על גבי ה-XIAO ESP32 והמסך שלך. 
הקוד כתוב בצורה נקייה (הערות באנגלית בלבד בקוד עצמו כדי למנוע בעיות קידוד), והוא מוכן לצריבה.

## מבנה התיקיות:
* `src/main.cpp`: קוד החומרה שרץ על ה-ESP32 (חיבור לאינטרנט, קריאת תמונות והדפסה למסך).
* `scripts/generate_images.py`: סקריפט פייתון שמייצר את כל תמונות המילים מהפונט.
* `data/`: תיקייה ריקה (לשם הסקריפט ישמור את התמונות, ומשם הן ייצרבו לזיכרון הפנימי של הלוח).
* `platformio.ini`: קובץ ההגדרות של PlatformIO (הגדרת ספריות ולוח).

## מדריך התקנה שלב-אחר-שלב:

### שלב 1: הכנת סביבת הפיתוח
1. ודא שמותקן אצלך Visual Studio Code עם תוסף PlatformIO.
2. פתח את תיקיית הפרויקט הזו (`Hebrew_Word_Clock`) בתוך VS Code.

### שלב 2: יצירת התמונות המנוקדות (מילים)
1. הורד את הפונט שבחרת, **Noto Serif Hebrew**, מהאתר Google Fonts.
2. חלץ את קובץ ה-`.ttf` (למשל `NotoSerifHebrew-Regular.ttf`) והעתק אותו לתוך תיקיית `scripts`.
3. פתח מסוף (Terminal) במחשב ונווט לתיקיית `scripts`.
4. ודא שמותקנת ספריית Pillow באמצעות הפקודה: `pip install Pillow`
5. הרץ את הסקריפט: `python generate_images.py`
6. בדוק שתיקיית `data` התמלאה בקבצי `.bmp` מוכנים.

### שלב 3: הזנת פרטי Wi-Fi
1. פתח את הקובץ `src/main.cpp`.
2. בשורות 10-11, החלף את `YOUR_WIFI_SSID` ו-`YOUR_WIFI_PASSWORD` בשם וסיסמת הרשת הביתית שלך.

### שלב 4: צריבה ל-ESP32
1. חבר את ה-XIAO ESP32 למחשב עם כבל USB נתונים.
2. בצד שמאל של VS Code, לחץ על סמל הנמלה של PlatformIO.
3. תחת Tasks -> seeed_xiao_esp32s3 -> Platform, לחץ על **Build Filesystem Image** ולאחר מכן על **Upload Filesystem Image**. זה יצרוב את התמונות לזיכרון!
4. תחת General, לחץ על **Upload** כדי לצרוב את קוד ה-C++.

הלוח יבצע אתחול, יתחבר לאינטרנט פעם אחת, ויצייר את השעה. תהנה!
